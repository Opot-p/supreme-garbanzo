# Проект: Онлайн Обучение (OnlineLearn)

## Структура проекта

```
/workspace
├── html/           # HTML страницы сайта
│   ├── index.html          # Главная страница
│   ├── login.html          # Страница входа
│   ├── register.html       # Страница регистрации
│   ├── admin.html          # Панель администратора
│   ├── teacher.html        # Кабинет преподавателя
│   ├── student.html        # Профиль студента
│   ├── course.html         # Страница курса с CRM
│   └── courses.html        # Список всех курсов
├── php/            # Бэкенд на PHP
│   ├── Database.php        # Класс для работы с JSON-базой данных
│   └── api.php             # API для всех операций
├── js/             # JavaScript логика
│   └── app.js              # Основной JS файл с функциями
├── css/            # Стили сайта
│   └── style.css           # Основные стили
└── db/             # База данных JSON
    └── database.json       # Хранилище всех данных
```

## Функционал

### Роли пользователей:
1. **Администратор** - может создавать аккаунты преподавателей
2. **Преподаватель** - может создавать курсы, уроки, задания, зачислять студентов
3. **Студент** - может проходить курсы, выполнять задания, проходить тесты

### Возможности:

#### Для администратора:
- Создание аккаунтов преподавателей
- Управление пользователями

#### Для преподавателя:
- Создание курсов
- Добавление уроков к курсам (текст, видео, практика, тест)
- Зачисление студентов на курсы
- Создание практических заданий и тестов
- Проверка работ студентов
- Выставление оценок
- CRM модуль для отслеживания успеваемости

#### Для студента:
- Просмотр доступных курсов
- Прохождение уроков
- Выполнение практических заданий
- Прохождение тестов
- Просмотр своих оценок
- Отслеживание прогресса

### Типы уроков:
- Текстовый урок
- Видеоурок
- Практическое занятие
- Тест

### CRM модуль:
- Отслеживание всех студентов курса
- Просмотр оценок за задания
- Результаты тестов
- Средняя успеваемость

## Запуск проекта

1. Установите PHP сервер (например, XAMPP, OpenServer или встроенный PHP server)
2. Запустите встроенный сервер PHP:
   ```bash
   cd /workspace/html
   php -S localhost:8000
   ```
3. Откройте браузер и перейдите по адресу: `http://localhost:8000`

## База данных

Данные хранятся в файле `db/database.json` в формате JSON.
База содержит следующие коллекции:
- users - пользователи
- teachers - преподаватели
- courses - курсы
- lessons - уроки
- enrollments - зачисления на курсы
- assignments - задания
- submissions - отправленные работы
- tests - тесты
- test_results - результаты тестов
